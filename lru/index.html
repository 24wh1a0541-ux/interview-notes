LRU Cache — built on a circular doubly-linked list

Every item is a node arranged in a ring. The top slot is always HEAD (most recently used). New or reused items get moved there. The slot just behind it is TAIL (least recently used) — the one that gets removed first when the cache is full.

Access the cache

PUT adds or updates a key and marks it most recent. GET reads a key and marks it most recent — or misses if it isn't cached.
