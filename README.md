## ✨ About the Project

An interactive visualizer that demonstrates how an
**LRU (Least Recently Used) Cache** works using a
**Circular Doubly Linked List**.

### 🎯 Features

- 🔵 HEAD — Most Recently Used
- 🟠 TAIL — Least Recently Used
- ➡️ Next / Previous pointers
- ⚡ PUT and GET operations
- 🗑️ Automatic LRU eviction
- 🎚️ Adjustable cache capacity
- 📊 Array visualization
- 📝 Real-time event log
- ▶️ Interactive demo mode
- 🔄 Reset functionality
